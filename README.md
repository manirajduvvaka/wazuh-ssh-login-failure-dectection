Wazuh SSH Login Failure Detection

Project Overview

A beginner-level Security Operations Center (SOC) lab project using Wazuh SIEM to monitor and investigate authentication-related security events on Ubuntu Server.

Objectives

- Monitor Ubuntu authentication logs.
- Identify failed authentication attempts.
- Investigate security alerts in Wazuh.
- Understand how a SOC analyst investigates suspicious events.

Tools Used

- Ubuntu Server 24.04
- Wazuh SIEM
- Windows PowerShell
- VirtualBox
- SSH
